A real local agent: terminal-first, with tools, vision, memory, and RAG.

Ollama Agent is a modern CLI and REPL to interact with local models through an Ollama-compatible API. It keeps persistent sessions, can run tools (like local shell commands), attaches screenshots with @dpN, and adds advanced capabilities with Mem0, Qdrant, and MCP servers.

Get started See capabilities
Install (pipx) 
pipx install git+https://github.com/arrase/ollama-agent.git
Key requirement: the selected model must support tool calling (capability tools), otherwise the app exits with a capability error.

Capabilities (what it actually does)

A concise overview of what’s implemented in the project runtime.

CLI + REPL

Fast mode (single prompt) and conversational mode with Markdown rendering and / commands.

  • ollama-agent -p "..." (non-interactive)
  • ollama-agent (REPL with history)

Persistent sessions

Automatically stores conversations and lets you list/load/delete sessions from the REPL.

  • SQLite storage in ~/.ollama-agent/sessions.db
  • Commands: /sessions, /session-load, /session-delete

Real tool calling

Integrates tools via function calling plus event streaming (calls, outputs, text deltas, reasoning deltas).

  • execute_command (local shell with timeout)
  • Events: tool_call, tool_output, text_delta, reasoning_delta

Screenshot vision

Attaches monitor screenshots in prompts via @dpN (N starts at 0) and converts them to multimodal input.

  • Supports multiple: @dp0 @dp1
  • On Linux requires DISPLAY or WAYLAND_DISPLAY

Persistent memory (Mem0)

Exposes tools to store and search memories: mem0_add_memory and mem0_search_memory.

  • Back-end: Mem0 + local Qdrant (configurable path)
  • Normalized result (success, error, data)

Local RAG (Qdrant)

Manages document databases, chunking, embeddings via Ollama, and local semantic search.

  • CLI commands: rag-create, rag-add, rag-search…
  • Tool: rag_search returns ready-to-use context

Reusable tasks

Save prompts as YAML tasks and run them by ID or prefix (CLI and REPL).

  • Directory: ~/.ollama-agent/tasks/*.yaml
  • Schema: title, prompt, model, reasoning_effort

Delegation via MCP

Loads optional MCP servers and exposes them as tools use_<name> (or a custom tool name).

  • Config: ~/.ollama-agent/mcp_servers.json
  • Each MCP can have its own model/instructions

Ollama compatibility

Uses an OpenAI-compatible client pointing by default to http://localhost:11434/v1/.

  • Supports per-session model switching (REPL: /model-set)
  • Validates effort: low|medium|high|disabled

Usage

Non-interactive mode

Ideal for quick queries or scripts; output is streamed to the console.

Example 
ollama-agent -p "List all files in the current directory as JSON."

Vision (screenshots)

Example 
ollama-agent -p "Describe what you see in @dp0"

RAG (load into the session)

Example 
ollama-agent --rag my-docs -p "What does the document say about X?"

Interactive REPL

A chat-like experience with / commands for sessions, models, tasks, and RAG.

Start 
ollama-agent
Command
What it does
/models
List available models and their tool support
/model-set <model>
Switch models without losing session context
/sessions
List persisted sessions

Architecture (overview)

Designed for streaming, tool calling, and local extensibility.

Interfaces
CLI (non-interactive) · REPL (chat + commands)
↓
Runner / Streaming
Normalized events: text, reasoning, tools, errors
OllamaAgent
OpenAI-compatible client → Ollama endpoint · SQLite sessions · Instructions
↓
Tools
Shell · Mem0 · RAG · (Optional) MCP servers as delegated tools
Data layers
Mem0/Qdrant (memory) · Local Qdrant (RAG) · ~./ollama-agent/*
↓
Vision
@dpN → capture via mss → multimodal input
Streaming: the console renderer shows Markdown deltas, “Thinking” (reasoning), and tool calls. If a tool takes too long, a configurable timeout applies.

Configuration and state

Files in ~/.ollama-agent/

  • config.ini — default model, endpoint, timeouts, etc.
  • sessions.db — persisted sessions (SQLite)
  • instructions.md — agent instructions
  • tasks/*.yaml — saved tasks
  • mcp_servers.json — MCP servers (optional)
  • rag/<name>/ — local RAG databases

Common parameters

Example 
ollama-agent -m "gpt-oss:20b" -e "high" -t 60 -p "What date is it today?"

Note: the --effort parameter currently only affects gpt-oss models; for other models it’s recommended to use disabled to avoid surprises.
