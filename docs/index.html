Your Local AI Assistant

A powerful command-line interface and REPL for interacting with local Ollama models.
Featuring tool execution, screen vision, memory management, and RAG capabilities.

Get Started View on GitHub

Key Features

Interactive REPL

Modern terminal-based chat interface with Markdown rendering, slash commands, and session history management.

Tool Execution

Empower your AI to execute shell commands and interact with your local environment to perform real tasks.

Task Automation

Save complex prompts and configurations as reusable tasks. Run frequently used workflows with a single command.

Deep RAG

Create and manage multiple vector knowledge bases. Index documents and directories to query them contextually.

Screen Vision

Let the model "see" your screen. Use @dpN to attach screenshots of display N for visual context.

Mem0 Memory

Persistent memory layer backed by Mem0 and Qdrant, allowing the agent to remember context across sessions.

MCP Support

Integrate with Model Context Protocol (MCP) servers to extend capabilities with external tools and data.

Getting Started

Requirements

Ensure you have Ollama running with a tool-capable model (like llama3.1) and an embedding model.

ollama pull gpt-oss:20b
ollama pull nomic-embed-text

Installation

pipx install ollama-agent

Interactive Mode

Start the chat interface to begin a session.

ollama-agent

One-off Commands

Execute a single prompt directly from your shell.

ollama-agent -p "Find large files in /var/log and summarize them"
